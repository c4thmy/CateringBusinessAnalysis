## 2. 测试目标与范围

### 2.1 测试目标

1. **验收数字可复现**：design §14 的 2025-09 vs 2024-09 全部关键数字在 engine、API、前端 mock、冒烟脚本四处一致；
2. **导入链路可控**：8 类模板在合法/非法/覆盖/回滚/编码场景下行为符合规格，坏数据不写入事实表；
3. **契约一致**：分析类与导入类接口统一响应结构（`{data, meta, insights}` / `{data}`），未知 `/api/*` 返回 JSON 404 而非 SPA HTML；
4. **页面可用**：17 个路由（10 可用页 + 6 骨架页 + 登录）无白屏、无 console error；缺数据用空态/「—」，不用 0 冒充；
5. **可回归、可放行**：形成 63+45+冒烟 + 手工的一键回归资产，支撑 2026-11-15 演示放行决策；
6. **安全基线**：未登录 401、Cookie httpOnly、静态托管路径穿越拦截、导入预览不泄漏内部键。

### 3.3 风险驱动优先级

| 风险 | 优先测法 | 证据 |
|---|---|---|
| 验收数字算错（演示失信） | 单元 + 接口 + mock 三重断言同一 fixtures | E/A/F-M 用例、14 §7 对照 |
| 导入写坏数据/覆盖累加 | 两阶段提交、覆盖标记、回滚、幂等 | I 用例、A07/A08 |
| 契约漂移（包裹结构/字段） | 接口结构断言 + 契约更新 + 前端 hooks | D-15~D-20 回归 |
| 缺数据用 0 冒充 | 空值断言 + 空态用例 | 预算 null、累计「—」、分位 hints |
| 页面白屏/异常 | 页面冒烟 + ErrorBoundary + 手工 | F-P 用例、截图 |
| 演示数据被测试破坏 | 临时库、冒烟隔离、备份 | A08、smoke 临时库 |
| 静态托管路径穿越/预览内部键泄漏 | 解析函数单测 + 接口断言 | A33/A34（v0.3.4） |
| 文档与代码不一致 | 计划/报告设「文档同步」检查项 | 14 §8、D-15~D-20 |

### 3.4 测试设计方法

- **等价类/边界值**：金额 0/负数/超 10MB；期间 `2025-09` vs `2025/9`；漏斗 0 与缺失；分位 <3 家；同期为 0。
- **场景法**：spec 场景 → 用例（登录、导入、下钻、漏斗、结论）。
- **错误推测**：坏 xlsx、GBK、未知 `/api`、重复行、未知门店/科目、覆盖回滚。
- **契约测试**：响应 key/结构/空值（`null` 不返回 0）、导入 `{data}` 包裹、未知 API JSON 404。
- **数据驱动**：`shared/fixtures` 同一 JSON 同时驱动 pytest 与 vitest。
- **安全边界**：SPA 路径 `../../` 逃逸、导入预览 `_` 前缀内部键、未知 `/api` 404、上传 10MB/编码边界。

### 5.2 优先级说明

- **P0**：影响演示主链路或对外数字，必须在演示前通过；失败即阻塞放行。
- **P1**：影响完整性/体验，演示前应通过；失败可降级（隐藏入口/话术说明）但需登记。
- 无 P2/P3：一期范围收敛，未实现能力不作为测试项（仅在骨架页验证可见性）。

### 5.3 进入/退出准则（按测试项）

- 进入：上一测试层通过或缺陷已登记；测试数据已加载；被测基线 tag 固定；环境自检通过。
- 退出：该测试项用例 100% 执行；P0 用例 0 失败；P1 失败已降级并登记；证据归档。
