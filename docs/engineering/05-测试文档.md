## 2. 测试目标、范围与策略

### 2.1 测试目标

1. 证明一期已实现能力符合 `specs/*/spec.md` 场景与 design.md 第 14 节验收数字；
2. 证明关键计算（利润桥、量价、漏斗、ROI、分位）在前后端两套实现中口径一致；
3. 证明导入链路（8 类模板、校验、两阶段提交、覆盖、回滚）在合法与非法输入下行为可控；
4. 证明演示动线在真实后端 + 真实数据库下可走通，页面不白屏、不报 console error；
5. 形成可复跑的回归资产（命令、临时库策略、10 步演示前检查）。

### 2.2 测试范围

| 范围内（一期，已测） | 范围外（一期未实现或未测，见第 10 节） |
|---|---|
| 登录 / 登出 / 会话（httpOnly JWT）与 401 | 多账号、角色权限、多租户 |
| 全局筛选（品牌/门店/期间/当月·累计/对比基准） | 预算基准与上期基准的完整链路 |
| 数据状态、8 类模板下载、上传校验、预览、确认、批次、回滚 | 与 POS/外卖平台 API 直连 |
| 经营总览（4 KPI + 分位 + 利润桥 + 结论） | 毛利、费用、顾客 & 竞争、总结 & 计划 |
| 营业利润对比（利润表 + 利润桥） | 沙盘推演与结果方案报告（含 PDF/PPT 导出） |
| 收入结构 / 同店异动 / 门店详情 / 渠道下钻 / 单渠道详情 / 产品下钻 / 结论与计划 | 移动端适配、多浏览器兼容矩阵、并发写入压力、真实大数据量 |
| 6 个骨架页的「可见、可导航、标注二期」 | 真实客户数据批量导入与性能指标 |

### 2.3 测试策略（V 模型 + 风险驱动）

| 项 | 值 | 说明 |
