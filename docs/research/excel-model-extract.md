## 二、核心公式与规则

### 2.1 连环替代法总则（原文引用）

出处 `营业利润连环替代法公式!A3:B23`，逐条原文：

| 出处 | 原文 |
| --- | --- |
| `A3` | 变动成本、销售费用随着收入变动而变动，不能用绝对值来分析 |
| `A4` | 利润=收入-收入\*成本率-收入\*销售费用率-收入\*税金率-固定成本 |
| `A5` | 利润=收入\*（1-成本率-销售费率-税金率）-固定成本 |
| `A6` | 利润=收入\*（毛利率-销售费率-税金率）-固定成本 |
| `A7` | 连环替代法： |
| `A8` | 分析因素改变，其他因素不变 |
| **`A9`** | **已经计算的因素，后面替换为本期数/实际数** |
| `B4` | 边际贡献=收入-变动成本（食材成本、外卖包材、人力提成、促销折扣）=固定费用+利润 |
| `B5` | 边际贡献率=（收入-变动成本）/收入 |
| `B6` | 边际贡献率+变动成本率=1 |
| `B7` | 利润=边际贡献-固定成本 |

三个文字示例（示例结果在单元格里**没有填入数值**，等号后为空）：

| 出处 | 原文 |
| --- | --- |
| `A10` | 1、收入下降8.7万对利润的影响如何计算？ |
| `A11` / `A12` | 25年利润=272\*（1-33%-47%）= ／ 26年利润=263.3\*（1-33%-47%）= |
| `A13` | 简化为：（本期收入-上期收入）\*（毛利率-变动成本率-税金率） |
| `A14` | 2、成本率增长1%对利润影响如何计算？ |
| `A15` / `A16` | 25年利润=263.3\*（1-33%-47%）= ／ 26年利润=263.3\*（1-34%-47%）= |
| `A17` | 简化为：本期收入\*（（1-本期成本率）-（1-上期成本率））or 本期收入\*（本期毛利率-上期毛利率） |
| `A19` | 3、销售费率增长2%对利润的影响如何计算？ |
| `A20` / `A21` | 25年利润=263.3\*（1-34%-47%）= ／ 26年利润=263.3\*（1-34%-51%）= |
| `A23` | 简化为： 本期收入\*（本期销售费率-上期销售费率） |

**规则提炼（三条，可直接落库为配置）**
1. 只替代一个因素，其他因素保持"已算过的用本期、没算的用基期"。
2. **变动项用"费率差 × 本期收入"**（因为变动费用随收入走，不能用绝对值）；**固定项用"本期绝对额 − 基期绝对额"再取反**。
3. 替代顺序 = 利润桥自上而下的科目顺序（收入规模 → 食材 → 优惠 → 水电气 → 宣传 → 工资 → 宿舍 → 店铺房租 → 其它费用），顺序不能乱。

| ① 综合毛利率：**产品销售结构 → 单品毛利率** | `第三步-毛利异动分析!B35:I47` | 结构影响 `E39 = =C39*D39`（占收入比差 × 基期毛利率）；毛利率影响 `H39 = =F39*G39`（毛利率差 × 本期占收入比）；合计 `I39 = =E39+H39` | 结构 −0.9455%、毛利率 −0.0443%、合计 **−0.9898%** |
| ② 综合毛利额：**收入 → 毛利率** | `第三步-毛利异动分析!B49:I61` | 收入影响 `E53 = =C53*D53`（收入差 × 基期毛利率）；毛利率影响 `H53 = =F53*G53`（毛利率差 × 本期收入） | 收入 +178.44、毛利率 −10.00、合计 **+168.44** |
| ③ 品类毛利额：**销量 → 单价 → 单位成本** | `第四步重点产品成本损益率分析!B40:G50` | 见下方原文 | 销量 +171.31、单价 +6.53、成本 −9.40、合计 **+168.43** |
| ④ 品类毛利率：**单价 → 单位成本** | `第四步产品毛利率分析!B9:G18` | 成本因素 `D11 = =(J10-M10)/J10-(J10-L10)/J10` = (基期成本−本期成本)/基期单价；单价因素 `F11 = =(K10-M10)/K10-(J10-M10)/J10` | 合计 −1.2608%（肉类） |

③ 的原文（`第四步重点产品成本损益率分析!I42:I45`）：

```
毛利额=销量*（单价-成本）
销量因素=本期销量*（同期单价-同期成本）-同期销量*（同期单价-同期成本）=（本期销量-同期销量）*（同期单价-同期成本）
单价因素=本期销量*（本期单价-同期成本）-本期销量*（同期单价-同期成本）=本期销量*（本期单价-同期单价）
成本因素=本期销量*（本期单价-本期成本）-本期销量*（本期单价-同期成本）=本期销量*（-本期成本+同期成本）
```

注意 ④ 与 ③ 的差别：③ 用**本期销量**承接单价与成本因素（量在前），④ 只拆单价与成本两因素，且成本因素用**基期单价**做分母——两者不能互相校验（同一"肉类"：③ 的单价因素 +24.93 万、④ 的单价因素 +1.34 个百分点）。

### 2.5 期间可切换：OFFSET 取数（`当月和累计数据对比分析`）

参数单元格：`E1` 开始时间=9、`E2` 结束时间=9（当月）；`L1`=1、`L2`=9（累计）。
`E2`、`L2` 是公式：`E2 = =E1`（"结束时间等于开始时间=当月数据"）、`L2 = =E2`（"结束时间等于左侧结束时间也就是当月"）。

取数公式（`C5`，2025 年本期）：

```excel
=SUM(OFFSET('2025年月利润表数据'!$D2,0,$E$1-1,1,$E$2-$E$1+1))
```

读法：以 `D2`（2025-01 收入）为锚点，向右移 `开始月-1` 列，取 `结束月-开始月+1` 列，纵向 1 行，求和。
同期列把锚点换成 `$R2`（2024-01 收入）。累计直接用 `L1=1 / L2=9` 得到 1~9 月。

- 当月：`C5`=1000、`E5`=760
- 累计：`K5`=7990、`M5`=4060

**这是全模型唯一的"周期性开关"**，标题也由它生成：`G3 = =E1&"月"`（"9月"）、`N3 = =L1&"月"&"  ——"`（"1月  ——"）、`O3 = =L2&"月累计"`（"9月累计"）。
