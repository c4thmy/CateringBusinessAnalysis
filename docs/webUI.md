典型的 B 端 SaaS 数据看板风格，整体接近 Ant Design 的设计语言，图表很像 ECharts 的默认风格。

布局结构
左侧导航：深色（藏青 / 近黑），宽约 320px。从上到下依次是 Logo（蓝色方块 "P" 加 "Profit Pilot"）、品牌切换框（杨博鸡公煲 ⇋）、菜单分组（顾问工作台、数据看板，"找问题"分组下有菜单诊断、健康度排行、产品分析、菜品角色、波士顿矩阵、价格分析、常点组合、多维对比），底部是数据状态（数据就绪 L5）和用户区（管理员、主题切换）。
顶部栏：白底。左边是页面标题，前面有一条蓝色竖线；右边是全局筛选：刷新、门店下拉（附带订单量）、日期区间、更多菜单。
内容区：浅灰底，上面放白色卡片，按栅格排列。上排是 3 列 KPI 卡片，下排是 2 列图表卡片。分区标题（"经营概览"）后面跟一条细分隔线。
右下角有一个悬浮的蓝色圆形 AI 对话按钮。
配色
主色：品牌蓝（约 #1F5BE0 / #2F54EB），用在选中态、链接、Logo 和 AI 按钮上。
语义色：红色表示下降 / 负向（毛利率 77.1%、环比 -0.7pp），绿色表示健康（成本覆盖率 100%），蓝色表示中性指标。
图表：柱子用纯色（绿 #52C41A、红 #FF4D4F），趋势图是浅绿柱加蓝色折线，双 Y 轴。
文字分层：标题是深灰黑，说明文字和分位数是浅灰，关键值（"本店 77.1%"）用蓝色加粗强调。
组件特征
KPI 卡片：指标名、图标加大号数值、副说明、环比变化（箭头加颜色）、"点击问 AI 排查原因 →"，最后一行是 P25 / P50 / P75 分位数加本店值。这种"对标分位"的设计很贴合本项目"对比找差异"的分析思路。
图表卡片：标题在左，右上角有描边的"AI 洞察"按钮。卡片内有分段选择器（营收 / 客单价 / 毛利率 / 订单量）加分组下拉，图表上方有一行分位线说明。
风格细节：圆角小（约 6–8px），边框细、阴影轻，信息密度中等偏高，没有渐变和装饰元素，偏理性、工具型。


设计亮点
AI 入口嵌在每个指标和图表旁边，不是只放一个全局聊天框。
每个指标都带同行分位数（P25 / P50 / P75），可以直接看出本店处在什么位置。
左侧菜单按分析任务组织（"找问题"），而不是按数据表组织。

技术栈是 React + Ant Design 5 + ECharts，或者 Vue 3 + Element Plus / Ant Design Vue + ECharts。
