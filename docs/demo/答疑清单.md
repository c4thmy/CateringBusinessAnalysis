# 答疑清单 · 收入分析 Demo

> 演示后最可能被问到的 15 个问题，按「业务 / 数据 / 产品 / 商用」分组。答案都已在本仓库文档里有出处。

## 业务口径

1. **这 240 万到底怎么来的？**
   新开店 143 万 + 同店 97.28 万；同店再拆客流 +92.07 万、客单 +5.08 万。来源：Excel「第二步-收入异动分析」表 6。
2. **同店和新店怎么定义？**
   一期按「对比期有收入 = 同店，无收入 = 新店」；Excel 没写门槛，已列入待确认（`data-caliber-notes.md` 第 10 节）。
3. **为什么同店拆解两项加起来是 97.16，收入变动是 97.28？**
   源表万元/人次/元不同精度取整造成 0.12 万尾差，页面有说明，不强行改数。
4. **连锁替代法替换顺序为什么不能变？**
   先量后价、先收入后成本、先整体后结构。先替换量、后面的价用本期值；顺序变了，各因素影响额就变了，但合计不变。
5. **边际贡献率 41.87% 怎么来的？**
   (760 − 195 − 188.4 − 32 − 26.4) / 760；PPT 讲「按同期 42% 边际贡献率」。
6. **食材成本率是 +1.04pp 还是 PPT 写的 2.3%？**
   Excel 是 1.04pp；PPT 第 14 页文字有误，已在差异清单记录，系统以 Excel 为准。

## 数据与导入

7. **客户的数据怎么进来？**
   8 类中文表头模板（利润表、门店收入、渠道、产品系列、单品、漏斗、时段、预算目标），上传→校验→预览→确认；错误给行号+列名+原因；支持批次回滚。
8. **客户 Excel 表头和模板不一样怎么办？**
   模板字段名与 Excel 原表一致；不在模板内的列会提示并给最接近的标准字段，人工映射后重新校验。
9. **数据重复导入会翻倍吗？**
   同数据集+门店+期间会提示覆盖，整体替换，不累加；批次可回滚。
10. **缺少同期数据会怎样？**
    页面显示「数据不完整」并列出缺失数据集，不用 0 冒充。

## 产品与技术

11. **AI 洞察是真的调大模型吗？**
    一期是规则引擎：按影响额排序取前三、阈值判断（费用率 ≤15%、毛利 ROI≥1、销售 ROI≥4、漏斗转化环比降 >1pp），规则来源是 PPT 知识库 67–79 页；二期可接大模型。
12. **能不能直接连 POS / 外卖平台？**
    一期先 Excel/CSV 导入；二期做 API 对接（架构已留 importer 抽象层）。
13. **能多品牌、多门店、多账号吗？**
    一期单管理员、单品牌演示；数据模型已带 brand/store 维度，二期加权限与多租户。
14. **沙盘推演在哪？**
    本期是页面骨架；二期做因子调整（客流、客单、渠道结构、毛利率、费率、固定费用）实时推演并生成结果方案。
15. **报告能导出吗？**
    本期留入口；二期出 HTML/PDF/PPT（老板版/运营版）。

## 商用

16. **这套东西卖多少钱、卖给谁？**
    面向连锁餐饮总部/区域运营：月度经营分析 + 门店诊断 + 沙盘推演 + 报告；按品牌/门店数订阅，先做收入模块单点验证付费意愿。
17. **和现有 BI 有什么区别？**
    不是给报表，是给「差异 → 原因 → 动作」：每个数字都能按因素拆到门店/渠道/菜品，结论直接对应整改动作。
18. **数据安全？**
    本地/私有化部署优先，账号与数据都在客户环境；不接第三方大模型，数据不出内网。
