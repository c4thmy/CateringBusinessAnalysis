## 问答 2：记录当前工程状态，是否用 git 打标签

**提问**

我想把当前工程状态记录下来，方便之后查找，是否是 git 打标签？

**回答**

是的。提交记录会一直往后增加，标签则固定指向某一次提交，可以按名字随时找回。

**操作**

1. 确认工作区干净，最新提交为 `3f4e93c CLAUDE init`（已包含 CLAUDE.md、`.claude/`、`openspec/`），本地和远程都还没有标签。
2. 打附注标签：

   ```bash
   git tag -a v0.1.0 -m "初始基线：业务参考资料(docs) + OpenSpec 脚手架 + CLAUDE.md，尚无源代码"
   ```

3. 介绍常用命令：

   ```bash
   git tag -n                  # 列出所有标签及说明
   git show v0.1.0             # 查看标签对应的提交
   git checkout v0.1.0         # 临时切回该状态，看完 git checkout main 回来
   git diff v0.1.0 main        # 对比当时和现在
   ```

4. 说明标签暂时只在本地，推送到 GitHub 需要执行 `git push origin v0.1.0`，等用户确认后再推。
