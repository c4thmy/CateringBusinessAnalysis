# Spec Delta

## Purpose

收入分析模块，对应月度报告"02 收入分析——流量 & 产品"：先拆收入结构，再用因素分析找出收入异动的原点（门店、渠道、客流/客单、系列/单品的销量/单价）。

## ADDED Requirements

### Requirement: 收入结构拆解
系统 SHALL 按以下维度分别展示本期收入、占比、对比值、对比占比、同比差额、增减率：经营模式（直营/加盟/联营）、在营门店类型（同店/新店/闭店）、区域、渠道（美团大众、扫码支付、线上活动优惠、美团外卖、饿了么外卖、京东外卖、抖音、会员储值消费、堂食现金等，渠道清单可配置）、渠道大类（堂食/外卖）。各维度的分项之和 MUST 等于总收入。

#### Scenario: 同店新店拆解
- **WHEN** 选择 2025-09、同期
- **THEN** 同店 857.23 / 759.95、新店 143 / 0、合计 1000.23 / 759.95，新店占比 14.3%

#### Scenario: 渠道结构
- **WHEN** 查看渠道维度
- **THEN** 美团大众本期 460、同期 336、差额 +124、增减率 +36.9%，且所有渠道合计等于总收入

### Requirement: 同店收入客流客单拆解
系统 SHALL 对同店收入按 客流 → 客单 的顺序做连环替代，输出全部同店及每家门店的客流影响和客单影响，并支持按门店下钻。

#### Scenario: 单店下钻
- **WHEN** 用户点击门店12
- **THEN** 系统显示门店12本期与同期的客流、客单、收入，以及客流差、客单差、客流影响额、客单影响额

### Requirement: 同店渠道异动
系统 SHALL 按渠道把本期收入拆成同店部分和新店部分：新店分摊 = 该渠道本期收入 ×（新店收入 ÷ 总收入），同店部分 = 该渠道本期收入 − 新店分摊；并计算各渠道同店的同比差额与增减率。Excel 模型「第二步-餐饮收入结构分析」另有一版按同期渠道占比分摊的结果，系统 MUST 在页面注明采用的口径。

#### Scenario: 同店渠道差额
- **WHEN** 查看同店渠道异动表
- **THEN** 每个渠道显示同期、本期同店、本期新店、同店差额和增减率，同店与新店之和等于该渠道本期收入；美团大众显示 394.23 / 336 / +58.24（+17.3%），新店分摊 65.77，且与 PPT 案例的 394 / 66 一致

### Requirement: 套餐收入量价拆解
系统 SHALL 对套餐收入按 销量 → 单价（实收单价 = 销售额 ÷ 销售数量）做连环替代，输出销售数量、销售额、实收单价、菜品收入、菜品优惠及占比、量差影响、价差影响；套餐与单品分开统计，套餐优惠率 MUST 可单独查看。

#### Scenario: 套餐增收来自量增价降
- **WHEN** 查看 2025-09 与 2024-09 的套餐量价表
- **THEN** 2024-09 为 432 单 / 66,080 元 / 152.96 元，2025-09 为 5,472 单 / 444,217.54 元 / 81.18 元，量差 +770,933.33 元、价差 -392,795.79 元、合计 +378,137.54 元

### Requirement: 时段客流下钻
系统 SHALL 在门店层按 日类型（工作日/节假日）× 时段（9:00-14:00、14:00-24:00、24:00-5:00）展示本期与同期的客流量、环比增长额与增长率，并标出对门店客流变化贡献最大的时段。

#### Scenario: 门店客流下降定位到工作日午餐
- **WHEN** 用户下钻门店12
- **THEN** 门店12 合计客流 4,556 → 4,276（-280，-6.1%），其中工作日 -465（-16.3%）、节假日 +185（+10.8%），系统点名工作日 9:00-14:00 与 14:00-24:00 为下降主因

### Requirement: 图文口径与尾差说明
同店收入、客流、客单均来自不同取整粒度的源表时（收入为万元、客流为整数人次、客单为元），系统 SHALL 在拆分结果与合计不一致时显示尾差说明，不得静默改写任一数字。

#### Scenario: 同店拆解尾差
- **WHEN** 同店收入变动 97.28 万，而客流影响 + 客单影响 = 97.16 万
- **THEN** 页面显示「两项影响合计 97.16 万，与同店收入变动 97.28 万相差 0.12 万，为源表取整尾差」，不影响「增长主要来自客流」的判断

### Requirement: 系列与单品销量单价拆解
系统 SHALL 对产品系列和单品（含套餐）的收入按 销量 → 单价 的顺序做连环替代，并按影响额排序，展示销量、销量占比、销售额、平均单价、菜品收入、菜品优惠及占比。

#### Scenario: 系列增收原因
- **WHEN** 查看同店系列收入异动
- **THEN** 系统列出每个系列的销量影响和单价影响，并给出结论文字，例如"增收主要来自肉类、涮品类、小料类的销量增加；主食类单价下降"

### Requirement: 点评曝光转化漏斗
系统 SHALL 展示门店的 曝光人数 → 访问人数 → 支付人数 漏斗、两级转化率及月环比，并与标杆门店（可选定）及品牌门店分位对比。缺失值 MUST 显示为"—"。

#### Scenario: 转化率下降提示
- **WHEN** 某门店访问-支付转化率环比下降超过 1 个百分点
- **THEN** 该门店在漏斗表中被标为异常

### Requirement: 线上平台费用效率
系统 SHALL 计算线上平台费用率（平台费用 / 平台收入）、毛利 ROI（平台毛利额 / 平台费用）和销售 ROI（平台销售额 / 平台费用），并与阈值对比（默认：费用率 ≤ 15%、毛利 ROI ≥ 1、销售 ROI ≥ 4，阈值可配置）。

#### Scenario: ROI 不达标
- **WHEN** 美团平台销售 ROI 为 3.2
- **THEN** 该指标标为未达标，并显示阈值 4

### Requirement: 收入异动汇总
系统 SHALL 汇总收入同比变动的来源：新店贡献、闭店减少、同店客流影响、同店客单影响，各项之和 MUST 等于总收入变动。

#### Scenario: 汇总收入 +240 万
- **WHEN** 查看 2025-09 收入异动汇总
- **THEN** 新店 +143、同店 +97.3（再拆为客流与客单），合计约 +240
