# Spec Delta

## Purpose

费用分析模块，对应月度报告"04 费用分析"：从费用科目的费率变动和经营效率指标（人效、坪效、租售比、上座次数、营销投产比）两个角度，找出费用偏高的原因。

## ADDED Requirements

### Requirement: 费用科目对比
系统 SHALL 按费用科目（优惠及手续费、水电气低值、宣传费用、工资奖金、宿舍房租、店铺房租、其它费用、税金及附加）展示本期金额、费率（占收入比）、对比金额、对比费率、增减额和费率变动（pp），并区分变动费用和固定费用，给出两类的小计。

#### Scenario: 其它费用增加
- **WHEN** 选择 2025-09、同期
- **THEN** 其它费用显示 84 / 47，增减 +37，并在利润影响中显示 −37 万

#### Scenario: 销售费率合计
- **WHEN** 查看变动费用小计
- **THEN** 系统显示销售费率合计及其同比百分点变动

### Requirement: 经营效率指标
系统 SHALL 计算以下指标：人效 = 收入 / 员工人数（万元/人/月）、人工成本率 = 工资奖金 / 收入、坪效 = 收入 / 营业面积 / 营业天数（元/㎡/天）、租售比 = 店铺房租 / 收入、上座次数 = 消费人次 / 餐位数 / 营业天数、营销投产比 = 营销带来的毛利额 / 营销费用。计算所需的基础数据缺失时，该指标 MUST 显示"—"并说明缺少哪项数据。

#### Scenario: 计算人效
- **WHEN** 门店当月收入 63 万、员工 15 人
- **THEN** 人效显示 4.2 万/人/月

#### Scenario: 缺少面积数据
- **WHEN** 门店没有营业面积数据
- **THEN** 坪效显示"—"，并提示"缺少营业面积"

### Requirement: 效率指标与模型值对比
系统 SHALL 把每个效率指标与模型值和预算值（可配置，例如人效 4.5 万/人/月、人工成本率 20%）对比，显示差值和是否达标，并按门店列出达标率（如"80% 门店人效达到 4.5 万"）。

#### Scenario: 人效未达标
- **WHEN** 人效 4.2 万，模型值 4.5 万
- **THEN** 指标显示"−0.3 万"并标为未达标

### Requirement: 门店费用排行
系统 SHALL 按门店对费率和效率指标排序，并显示品牌内 P25 / P50 / P75 分位，便于找出费用异常的门店。

#### Scenario: 租售比最高的门店
- **WHEN** 用户按租售比降序排序
- **THEN** 列表显示租售比最高的门店在前，超过 P75 的门店标为异常
