# Spec Delta

## Purpose

毛利分析模块，对应月度报告"03 毛利分析——销量、单价 & 成本"：拆解毛利额和毛利率的变化，定位到产品系列、单品，以及实际成本和理论成本之间的差异。

## ADDED Requirements

### Requirement: 毛利总览对比
系统 SHALL 展示本期与对比期的收入、食材成本、毛利额（收入 − 食材成本）、毛利率，以及增减值、增减率和毛利率百分点变动。

#### Scenario: 2025-09 毛利率同比
- **WHEN** 选择 2025-09、同期
- **THEN** 毛利额 733 / 565，毛利率 73.3% / 74.3%，毛利率变动 −1.0pp

### Requirement: 毛利率变动拆分
系统 SHALL 按产品系列把综合毛利率变动拆成产品销售结构影响和单品毛利率影响（规则见 factor-analysis-engine），并列出每个系列的收入占比变化、毛利率变化和两类影响。

#### Scenario: 结构与毛利率影响
- **WHEN** 查看毛利率变动拆分
- **THEN** 系统显示结构影响 pp、毛利率影响 pp，两者之和等于综合毛利率变动，并标出影响最大的系列

### Requirement: 毛利额连环替代
系统 SHALL 对每个产品系列和重点单品按 销量 → 单价 → 单位成本 的顺序拆解毛利额变动，输出三项影响和合计，并给出全部产品的汇总。

#### Scenario: 肉类毛利额拆解
- **WHEN** 查看肉类系列
- **THEN** 系统显示销量影响、单价影响、单位成本影响（万元）及三项合计，合计等于肉类毛利额同比变动

#### Scenario: 缺少销量数据
- **WHEN** 某系列只有收入和成本，没有销量
- **THEN** 该系列只显示毛利额变动总额，并提示"缺少销量，无法拆分"

### Requirement: 单价与成本对毛利率的影响
系统 SHALL 对每个系列计算：成本因素影响 = (同期单价 − 本期单位成本) / 同期单价 − (同期单价 − 同期单位成本) / 同期单价；单价因素影响 = (本期单价 − 本期单位成本) / 本期单价 − (同期单价 − 本期单位成本) / 同期单价。两者之和 MUST 等于该系列毛利率变动。

#### Scenario: 系列毛利率影响
- **WHEN** 查看锅底类
- **THEN** 系统显示单价差异、单价对毛利率影响、成本差异、成本对毛利率影响和总影响

### Requirement: 理论成本损益
系统 SHALL 对每个系列和重点单品计算：理论成本 = 收入 × (1 − 理论毛利率)，成本损益 = 实际成本 − 理论成本，理论成本率差 = 实际毛利率 − 理论毛利率。实际成本高于理论成本标为"超耗"，低于理论成本标为"低于理论"，两者都要提示检查（分量、盘点、下单漏洞）。

#### Scenario: 小料类超耗
- **WHEN** 小料类实际成本高于理论成本
- **THEN** 该行标为"超耗"，显示成本损益金额，并排在损益绝对值排序的前列

### Requirement: 折扣率对成本率的影响
系统 SHALL 用 成本率 = 实际食材成本 / (原价销售额 × (1 − 折扣率)) 反推原价销售额，并把成本率变动拆成原价销售额变化、折扣率变化、实际成本变化三项影响，三项之和 MUST 等于成本率变动。

#### Scenario: 反推原价销售额
- **WHEN** 2024-09 实收 760 万、折扣率 23.26%
- **THEN** 原价销售额约 990.3 万

#### Scenario: 缺少折扣率
- **WHEN** 当前期间没有原价销售额或优惠数据
- **THEN** 折扣率分析卡片提示缺少数据，不输出影响
