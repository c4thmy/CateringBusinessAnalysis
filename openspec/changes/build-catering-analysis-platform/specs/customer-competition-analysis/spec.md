# Spec Delta

## Purpose

顾客与竞争分析模块，对应月度报告"05 顾客 & 竞争分析"：衡量顾客满意度和会员经营状况，并把本店与同商圈竞对比较，找出提升点。

## ADDED Requirements

### Requirement: 多渠道加权满意度
系统 SHALL 按渠道（线上平台评价、扫码即时评价、外卖平台评价、线下明访，渠道和权重可配置，默认权重之和为 100%）计算加权满意度总分，并展示各渠道得分和较上期的变化。权重之和不等于 100% 时 MUST 拒绝保存。

#### Scenario: 加权总分
- **WHEN** 各渠道得分为 4.7 / 5.0 / 4.4 / 4.8，权重为 40% / 25% / 20% / 15%
- **THEN** 总分为 4.71

#### Scenario: 权重配置错误
- **WHEN** 用户把权重改为合计 90%
- **THEN** 系统提示"权重之和必须为 100%"，不保存

### Requirement: 分项满意度
系统 SHALL 展示口味、服务、环境等分项评分及与目标值的差距。

#### Scenario: 分项低于目标
- **WHEN** 口味评分 4.6，目标 4.8
- **THEN** 口味标为未达标，差距 −0.2

### Requirement: 评价关键词分析
系统 SHALL 对导入的评价文本按好评和差评分别统计关键词词频，用词云和排行展示，并支持点击关键词查看原始评价。

#### Scenario: 查看差评关键词
- **WHEN** 用户点击差评词云中的"肉太瘦"
- **THEN** 系统列出包含该关键词的差评原文、渠道和日期

### Requirement: 会员与储值指标
系统 SHALL 展示会员数（上月末、本期新增）、复购率、留存率、储值沉淀（上月末、本月储值、本月消费、期末沉淀）、会员消费单量占比、营收占比、平均客单及环比，并与目标值对比（如会员营收占比目标 20%）。

#### Scenario: 会员占比低于目标
- **WHEN** 会员营收占比 15%，目标 20%
- **THEN** 指标标为未达标，差距 −5pp

### Requirement: 竞对监测
系统 SHALL 维护同商圈竞对（不少于 1 家，建议 3 家）的监测项，例如客单价、评分、评价数、套餐价格、上新频率，并展示本店值、各竞对值、竞对均值和本店与均值的差异。监测项可配置，数值型监测项计算差异，文本型监测项只做并列展示。

#### Scenario: 客单价对比
- **WHEN** 本店客单价 68，竞对 A / B / C 为 72 / 65 / 70
- **THEN** 竞对均值 69，本店与均值差异 −1
