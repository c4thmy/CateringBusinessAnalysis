# Proposal

## Why

现在的月度经营分析靠一份 Excel 模型（`docs/利润桥及毛利率分析-高维第二期261003.xlsx`）加一份 80 页 PPT 模版（`docs/高维学堂经营分析与科学决策月度分析模版20261002.pptx`）手工完成。数据靠复制粘贴，公式靠 OFFSET 跨表引用，换一个月、换一家门店就要重做一遍，"假如客单价提高 5 元利润会怎样"这类推演也做不了。要把"比差异 → 找问题 → 定计划 → 达目标"这套方法做成一个 Web 系统：导入数据后自动出分析结果，还能做沙盘推演，并把推演结果转成可执行的方案。

## What Changes

- 新建 Web 系统（仓库目前没有代码，属于从零搭建）。界面沿用 `docs/webUI.md` 记录的 Profit Pilot 风格：深色侧边导航、白色顶栏放全局筛选（品牌 / 门店 / 期间 / 对比基准）、浅灰内容区上的卡片栅格、KPI 卡片附 P25/P50/P75 分位。
- 数据导入：上传 Excel/CSV 模板（月度利润表、预算、渠道收入、门店收入、产品销售与成本、点评曝光转化、满意度、竞对监测、会员、时段上座），先校验、预览，再入库，并保留导入批次记录。
- 营业利润分析：预算达成率、利润表本期 vs 同期/预算/上期（当月与累计）、利润桥（收入、毛利率、销售费率、固定费用的连环替代贡献）、经营综合评分、集团多业务板块汇总。
- 收入分析：经营模式、同店/新店/闭店、区域、渠道、系列/单品等结构拆解；同店异动拆成客流 × 客单；单品异动拆成销量 × 单价；点评曝光 → 访问 → 支付转化漏斗；线上平台费率与 ROI。
- 毛利分析：毛利额/毛利率对比；毛利率变动拆成产品结构影响 + 单品毛利率影响；毛利额按 销量 → 单价 → 单位成本 连环替代；单价与成本对毛利率的影响；实际成本 vs 理论成本的损益；折扣率对成本率的影响。
- 费用分析：费用科目对比与费率变动、人效 / 人工成本率、坪效 / 租售比、上座次数、营销投产比，与模型值/预算值对比。
- 顾客 & 竞争分析：多渠道加权满意度、好评/差评词频、会员与储值指标、竞对监测表。
- 总结 & 计划：自动汇总各模块的结论要点，制定下月目标（收入、营业利润、毛利率、满意度），维护待办整改清单（维度、事项、目标、方案、期限、部门、责任人、状态），可导出。
- 沙盘预演：在基期数据上调整驱动因子（客流、客单、渠道结构、毛利率/折扣率、费率、固定费用、时段上座与客单），实时算出利润表和利润桥；多方案对比、保存；选定方案后输出"结果方案"（目标分解 + 建议整改项 + 导出），可一键转成计划。
- 共用计算引擎：连环替代法、对比差异、分位数，做成纯函数并配单元测试，用 Excel 模型里的数值做验收基准。

## Capabilities

### New Capabilities
- `app-workspace`：应用框架、导航、全局筛选（品牌 / 门店 / 期间 / 对比基准）、KPI 卡片与分位展示规范。
- `data-import`：导入模板、校验、预览、入库、批次管理与数据就绪状态。
- `factor-analysis-engine`：对比差异、连环替代法、利润桥、分位数等共用计算规则。
- `profit-analysis`：营业利润分析（预算达成、利润表对比、利润桥、综合评分、板块汇总）。
- `revenue-analysis`：收入结构与异动分析（流量 & 产品）。
- `gross-margin-analysis`：毛利分析（销量、单价 & 成本，理论成本损益，折扣率影响）。
- `expense-analysis`：费用与效率指标分析。
- `customer-competition-analysis`：顾客满意度、会员与竞对分析。
- `summary-plan`：月度总结、下月目标与待办整改清单。
- `sandbox-simulation`：沙盘预演、多方案对比与结果方案输出。

### Modified Capabilities
（无，仓库目前没有已有规格）

## Impact

- 新增前端工程（React + TypeScript + Vite + Ant Design 5 + ECharts）和后端工程（Python FastAPI + SQLAlchemy + SQLite，后续可换 PostgreSQL）。目录与命令在 design.md 中确定，落地后补写到 `CLAUDE.md`。
- 新增依赖：前端 antd、echarts、react-router、@tanstack/react-query；后端 fastapi、sqlalchemy、pandas、openpyxl、pytest。版本锁定。
- `docs/` 下的原始文件只读，作为口径和验收基准，不修改。
- 不在本次范围：真实的 AI 对话/大模型洞察（界面上的"AI 洞察"入口先做成基于规则的文字结论）、第三方平台 API 自动拉数、多租户权限体系（只做单管理员登录）、移动端适配。
